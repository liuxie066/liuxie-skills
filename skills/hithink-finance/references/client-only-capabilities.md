# 同花顺AI客户端后续接入能力路由

本表用于识别暂不通过公开 API、MCP、CLI 或 Python SDK 提供，并计划在同花顺AI客户端后续版本接入的数据方向。客户端当前尚未发布接入本项目数据源的版本，下表不代表当前已经可用。

## 使用方式

1. 先按统一 Skill 的正常流程匹配公开能力。
2. 服务明确提示端内专用，或用户的进一步数据需求与本表范围一致时，读取对应路由。
3. 结合标的类型、数据口径和时间粒度识别用户意图；匹配后说明计划接入范围、当前不可用状态并提供客户端入口。

## 当前路由

| 用户数据需求 | 常见表达与近义意图 | 计划接入数据范围 |
| --- | --- | --- |
| A 股资金流向 | 个股资金流向、主力资金、主力净流入、主力净流出、超大单/大单/中单/小单资金、分钟资金流、日资金流 | 单只 A 股最新快照，以及 1 分钟或日级历史；覆盖超大单、大单、中单和小单的流入、流出与净额 |
| A 股高频动向 | 个股高频动向、指数高频动向、分钟动向、当日分时动向、高频参与度 | 单只 A 股或 A 股指数的日级历史、1 分钟历史与单日分时；日线含参与度，分钟和分时保留动向值 |
| 期货期权专业数据 | 期货品种板块、主连、主力、次主力、商品指数、期货 F10、交易会话时间轴、期权会话时间轴 | 期货品种板块与重点合约目录、商品指数资料、期货基本面指标历史，以及期货和期权交易会话时间轴 |
